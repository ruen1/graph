This is a complete open-source re-implementation of the Telegraph writing service; comes with API-compatible backend and TUI moderation panel.

Benefits over telegra.ph:
- 128,000 character limit compared to 64,000
- No callbacks to t.me and no telemetry
- Removes EXIF metadata from uploads before publish
- Removes common tracking parameters from links
- Highly portable with SQLite database
- No more jQuery! (almost, theres a shim)
- Hand-made SVG icons everywhere. No more sprite sheets.
